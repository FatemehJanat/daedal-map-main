# Public Docs

These are the public GitHub docs for people who want to run, extend, or inspect
the open DaedalMap runtime.

Start here if you are using this repo as a local or self-hosted runtime.

## Recommended reading order

1. [../README.md](../README.md)
2. [LOCAL_AND_HOSTED.md](LOCAL_AND_HOSTED.md)
3. [DATA_SCHEMAS.md](DATA_SCHEMAS.md)
4. [APP_OVERVIEW.md](APP_OVERVIEW.md)

## What each doc is for

- [LOCAL_AND_HOSTED.md](LOCAL_AND_HOSTED.md)
  Runtime modes, environment choices, and the practical self-host path.
- [DATA_SCHEMAS.md](DATA_SCHEMAS.md)
  Public data-shape rules, `loc_id`, and the schema conventions the runtime expects.
- [APP_OVERVIEW.md](APP_OVERVIEW.md)
  Higher-level runtime/app model and how the open runtime relates to the broader product.

## What is not here

This public docs folder is for self-host, runtime, schema, and integration
readers.

Hosted operator notes, deployment runbooks, release-control details, and
private product planning belong outside the public repo docs.
